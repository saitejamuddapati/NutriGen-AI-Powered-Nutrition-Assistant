# NutriGen – AI Powered Nutrition Assistant

NutriGen is a lightweight web application that uses Google’s Generative AI to provide nutritional insights for food items based on text descriptions or images.  
The application focuses on practical AI integration, clean user experience, and reliable information delivery rather than complex model training.

---

## Problem Statement
Understanding nutritional information from food items is often time-consuming and confusing for users.  
NutriGen aims to simplify this process by allowing users to input a food description or image and receive a clear breakdown of calories, macronutrients, and key micronutrients.

---

## Key Features
- Accepts **text descriptions or food images** as input
- Generates structured nutritional information:
  - Calories
  - Macronutrients (proteins, carbohydrates, fats)
  - Key micronutrients
- Clean and interactive user interface
- Fast and easy-to-understand responses powered by Generative AI

---

## Approach
- Built a Streamlit-based web interface for user interaction
- Integrated Google Generative AI APIs to analyze user input
- Designed prompts to return structured, user-friendly nutrition summaries
- Focused on clarity, usability, and consistency of AI outputs

This project emphasizes **applied Generative AI usage** rather than training custom machine learning models.

---

## Tech Stack
- **Programming Language:** Python
- **Web Framework:** Streamlit
- **AI Service:** Google Generative AI (Gemini)
- **Libraries:** Streamlit, Pillow, Requests
